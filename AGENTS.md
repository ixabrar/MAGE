# AGENTS.md — MAGE

## Structure

- `frontend/` — Next.js 16.3.3 + React 19 + Tailwind v4 (App Router, `@/*` → `frontend/src/*`). Pages in `frontend/app/`, components in `frontend/src/`.
- `backend/` — FastAPI + Pydantic + Supabase (`backend/src/`). Entrypoint `backend/src/main.py`. No `database/` dir yet despite README reference.
- `fusion-layer/` — Copied ARM/PFM fusion + mock models (`arm/`, `mock_models/`, `data/error_history.json`). Original source `D:/ARM+PFM/fusion/` must not be touched (per `MAGE_REPOSITORY_MAP.md`).

```
Frontend (Next.js) → POST /api/assessment → Backend adapters → Mock Models → ARM.compute_weights() → PFM.fuse() → FusionResult
```

Detailed layer ownership and where-to-edit table: `MAGE_REPOSITORY_MAP.md`.

## Architecture Gotchas

- **Backend imports assume `backend/src` on `sys.path`.** Adapters/services use `from schemas.fusion import` / `from adapters.* import` (not `src.schemas`). Running `python -m uvicorn src.main:app` from `backend/` works only if `src` is importable; if you hit `ModuleNotFoundError: No module named 'routes'`, run with `PYTHONPATH=src` or from `backend/src`. `fusion_service.py:17` and adapters work around this for `fusion-layer` via `sys.path.insert(0, str(fusion_layer_path))`.
- **Fusion-layer import path is fragile.** `backend/src/services/fusion_service.py:17` resolves `fusion-layer` as `Path(__file__).parents[2] / "fusion-layer"` — this only works when backend and fusion-layer are siblings at repo root. Don't move either.
- **ARM singleton with curated history.** `fusion_service.py:71` caches `_arm_instance` via `build_arm_with_history()` seeded with hardcoded error profiles (dorsal/face/blood). `build_profiles()` must be called before `compute_weights()`. Mock adapters call `face_mock("middle")` etc. — preserve `ModelPrediction` contract (`model_name`, `predicted_age` 0-120, `confidence` 0-1, `age_bins` summing to ~1) when swapping to real models.
- **Assessment storage is in-memory.** `backend/src/routes/assessment.py:13` `_assessments: Dict[str, dict] = {}` — restarted backend loses all assessments. `GET /api/assessment/{id}` 404s after restart. Supabase client exists at `backend/src/core/supabase.py` but is not yet wired to assessments; importing it crashes if `SUPABASE_URL`/`SUPABASE_ANON_KEY`/`SUPABASE_SERVICE_ROLE_KEY` are unset (dotenv).
- **CORS locked to localhost.** `backend/src/main.py:15` `allow_origins=["http://localhost:3000"]` only.
- **Frontend never calls ARM/PFM directly** — always via `POST http://127.0.0.1:8000/api/assessment` then poll `GET /api/assessment/{id}` (`MAGE_REPOSITORY_MAP.md` golden rule).

## Frontend Quirks

- **Tailwind v4, not v3.** `frontend/app/globals.css:1` uses `@import "tailwindcss"` + `@theme { --color-* }` and `frontend/postcss.config.mjs` uses `@tailwindcss/postcss`. Don't add `@tailwind base/components/utilities` or a v3 `tailwind.config` content globs will mismatch if you add new directories.
- **Path alias:** `frontend/tsconfig.json:22` `@/*` → `./src/*` (relative to `frontend/`, not repo root).
- **Next.js auto-managed file:** `frontend/AGENTS.md` and `frontend/CLAUDE.md` contain the `BEGIN:nextjs-agent-rules` block generated by `next dev` (`node_modules/next/dist/server/lib/generate-agent-files.js`). Don't delete that block or `next dev` recreates the dirty diff — commit it if you touch frontend.
- **`suppressHydrationWarning` is intentional.** Applied in `frontend/app/layout.tsx:33` and landing page containers to silence Brave extension `bis_skin_checked` injection mismatches. Don't remove.
- **Auth is dev-bypassed.** `frontend/middleware.ts:6` / `frontend/src/lib/auth.ts` — `NEXT_PUBLIC_DEV_AUTH_BYPASS=true` skips all auth checks; user store is an in-memory `Map` with naive `hashPassword` (`auth.ts:10`) — never ship to prod. `AUTH_SECRET` must be set for JWT otherwise.

## Conventions

- **Where to edit:** UI → `frontend/`, API route → `backend/src/routes/`, orchestration → `backend/src/services/assessment_service.py`, adapter → `backend/src/adapters/`, fusion math → `fusion-layer/arm/`. See `MAGE_REPOSITORY_MAP.md:279`.
- **Don't log biometric data.** Per `SECURITY_HARDENING.md` — never log raw face/hand/blood inputs or auth tokens; file-type validation belongs in backend.
- **Design tokens:** colors/fonts in `frontend/src/lib/design-tokens.ts` and `frontend/app/globals.css` `@theme` + `frontend/tailwind.config.ts` — keep them in sync.
- **ESLint at repo root** (`eslint.config.mjs`) ignores `.next/**`, `out/**`, `build/**`, `next-env.d.ts` via `globalIgnores`.
